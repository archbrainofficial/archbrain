What The ₦2,500 Actually Pays For

1. 🖥️ Server Running 24/7

Your phone's location updates every 30 seconds.

That means our server receives and stores

2 location updates per minute × 60 minutes

× 24 hours = 2,880 data points per day

per device.



Someone has to pay for that server.

That someone is the subscriber.

2. 📡 Real-Time GPS Tracking

Free plan:  Basic tracking (updates every 5 mins)

Premium:    Live tracking (updates every 30 secs)



The difference = faster recovery if stolen.

A thief can move far in 5 minutes.

30-second updates = you know exactly where they are.

3. 🗑️ Remote Wipe Capability

This is powerful and dangerous if misused.

Premium users get this feature because:

→ It requires identity verification

→ It uses Firebase push infrastructure

→ It must be logged and audited for legal reasons

All of that costs money to maintain.

of users requires serious database storage.

That storage has a real monthly cost.

Nigerian SMS rates = ₦4 - ₦15 per message.

Premium users get unlimited SMS alerts.

ARCHBRAIN absorbs that cost from the ₦2,500.
